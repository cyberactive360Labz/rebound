# REBOUND Project Charter

## Overview

Rebound is a modern browser-based arcade game where players control platforms to keep an energy Orb in motion. The project is designed to showcase professional software engineering practices, including modular architecture, cybersecurity, documentation, CI/CD, and modern frontend/backend development.

## Vision

Every bounce should feel satisfying.

## Objectives

- Build a polished browser game
- Learn advanced game architecture
- Showcase Go backend development
- Demonstrate PixiJS rendering
- Build production-quality documentation

## Target Platforms

- Chrome
- Firefox
- Edge
- Safari

Frontend
